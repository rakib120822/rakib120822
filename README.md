# 🍄 About Me

Hi! I'm Rakib from Chattogram, Bangladesh. I'm a Petroleum and Mining Engineering student at **CUET** who found his passion in web development, and I build responsive, production-ready applications.

My main toolkit is **React, Next.js, Node.js, MongoDB, PostgreSQL, Prisma, and TypeScript**, and I've shipped apps with authentication, role-based access, and payment integration.

I've also solved **100+ problems on Codeforces**, which keeps my data structures and problem-solving skills sharp. Like Mario collecting coins, I'm always leveling up my skills and exploring new technologies. ⭐
