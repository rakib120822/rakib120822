# 💫 About Me

Hi! I'm Rakib from Chattogram, Bangladesh. I'm a Petroleum and Mining Engineering student at **CUET** who found his passion in web development. I build responsive, production-ready applications with **React, Tailwind CSS, Node.js, Express, and MongoDB**, including authentication, role-based access, and payment integration.

I've also solved **100+ problems on Codeforces**, which keeps my data structures and problem-solving skills sharp.
